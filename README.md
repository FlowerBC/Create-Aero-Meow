# 基米动力：航空学

> 英文名称：`Create Aero Meow`
> 许可证：GPL-3.0-or-later

“基米动力：航空学”是一套以 **机械动力（Create）** 为核心的整合包。内容围绕自动化工业、猫咪动力、流体与物流、陆空载具及世界探索展开，玩家可以从基础工坊开始，逐步建立完整的生产、运输和航空体系。

本整合包名称来源于两个核心附属：

- **机械动力：老吴学（Create: Meowchanics）**：将猫咪、哈气与机械动力生产体系结合，扩展出猫咪能源、加工、装备和物流内容。
- **机械动力：航空学（Create Aeronautics）**：加入基于物理的载具、越野和飞行系统，可用于构建汽车、飞机及大型移动结构。

## 核心内容

### Create 与核心附属

| 内容 | 说明 |
|---|---|
| Create | 自动化、机械动力、物流和列车系统 |
| Create: Meowchanics | 猫咪工业链与哈气生产系统 |
| Create Aeronautics | 基于物理的载具、越野和飞行系统 |
| Create: Diesel Generators | 柴油动力与相关加工设备 |
| Create: Connected | 补充 Create 的机械与物流组件 |
| Create: Enchantment Industry | 液态经验与附魔工业内容 |
| Create Big Cannons | Create 风格的火炮和弹药系统 |
| Create Ore Excavation | 矿脉勘查与自动开采系统 |
| Create: Power Loader | 区块加载与非玩家活动控制 |
| Create: Things and Misc | Create 风格的功能方块和物品 |

### 工业与物流扩展

整合包还包含多种面向生产、仓储和运输的内容，包括：

- Create: Vintage Improvements
- Create: Stuff 'N Additions
- Storage Drawers 与 Fluid Drawers Legacy
- Sophisticated Backpacks 与 Sophisticated Core
- FTB Quests、FTB Teams 与 FTB Ultimine
- JEI、Jade、Xaero 小地图和世界地图
- 输入法修复、界面美化、汉化资源与语言更新

这些内容共同提供材料加工、流体处理、仓储分类、地图辅助和多人协作能力。

### 性能与渲染组件

整合包包含常用的性能与渲染组件，例如 Sodium、Iris、ModernFix、FerriteCore、EntityCulling 和 ImmediatelyFast，用于提供渲染选项、资源加载优化和实体剔除能力。实际帧率会受到硬件、渲染距离、世界规模和游戏设置影响。

### KubeJS 内容调整

整合包包含少量 KubeJS 调整，主要用于：

- 整理 Create Ore Excavation 的矿脉与钻探配方
- 为 Vintage Improvements 离心机增加扳手切换红石状态的交互
- 为 Create 流体管道增加右键端口切换交互
